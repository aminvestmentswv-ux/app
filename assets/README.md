# AM Investments brand asset

`am-investments-logo.jpg` is the unmodified A&M Investments logo displayed in the
header of the official company website, https://www.aminvestmentswv.com/.

Original image URL:
https://image-cdn.carrot.com/uploads/sites/4396/2018/05/rsz_logo_final_72dpi.jpg

The downloaded JPEG is 216 × 180 pixels. It is bundled with the app so displaying
the company logo does not require an external image request.

The user selected the logo's navy-and-gold palette for the app:

- Navy blue: `#133c7a`.
- Gold: `#e0ad2d`.

These colors were sampled from the original logo. White-on-navy text has a
10.74:1 contrast ratio; navy-on-gold button text has a 5.21:1 contrast ratio.
