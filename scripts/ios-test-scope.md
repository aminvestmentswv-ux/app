# iOS native test-only scope

Push/manual-dispatch workflow is restricted to the approved test/native-live-feed-2026-11-07 branch in a public repository. macos-26 is a standard hosted runner. No production signing, Apple account, store upload, deployment, secret or OS/network-security change is used. The runner creates only disposable app configuration and QA overlay instrumentation. Evidence retention is three days.

The XCTest target builds with the app in Release configuration and installs it in an available iPhone simulator. It asserts launch without Metro, real feed success, a new refresh request on retry and foreground, all four filters, empty and address search, detail fields and Close/reopen, photo next/previous/wraparound counters, simulated feed failure retaining listings, live-feed recovery and cold relaunch. Fault injection affects only the feed fetch; it does not turn off network connectivity. The test-only QA bar can affect the layout and must not be mistaken for production UI.

XCTest screenshots are attached to the xcresult and exported as artifacts. Review their pixels before judging layout/branding/photo rendering. Gallery counters do not prove correct photo pixels or gesture swiping. Close is the iOS detail-back action; sheet swipe dismissal is not tested. Safe areas, iPad, multiple iPhone sizes, offline first launch, timeouts/malformed/stale responses, actual radio loss, external calls/maps/sharing and physical iPhone/TestFlight remain untested by this suite. Tests use live inventory at execution; a subsequent feed change may require fixture reconciliation, never suppression of assertions.

Local preparation validation checks YAML, shell syntax, embedded JavaScript/Python syntax, safety gates and Linux fail-closed behavior. Ruby, Swift/XCTest, CocoaPods build and iOS runtime validation require the hosted Mac. No iOS pass is claimed before that actual run and screenshot review. A passed Android baseline does not cover these newer native client changes.
